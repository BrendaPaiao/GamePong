# GamePong

Projeto pessoal em desenvolvimento com o objetivo de criar uma versão do jogo clássico Pong, explorando conceitos de jogos em tempo real e a integração entre frontend e
backend.

## Sobre o projeto
O GamePong é um projeto de estudo focado na construção da estrutura de um jogo Pong com interação em tempo real entre os usuários. A proposta é compreender melhor como
funcionam jogos multiplayer simples e a comunicação entre cliente e servidor.

O projeto foi desenvolvido como estudo prático a partir de aulas online, servindo como base para aprofundamento dos conceitos apresentados e adaptação dos conhecimentos
adquiridos. É uma iniciativa pessoal voltada à fixação de conteúdos, aprendizado de novas tecnologias e a exploração de uma área diferente da programação.

## Tecnologias utilizadas
- JavaScript
- Node.js
- React
- WebSocket
- Nodemon

## O que estou aprendendo
- Comunicação em tempo real utilizando WebSocket
- Estruturação de jogos simples
- Organização de projetos frontend e backend
- Base prática em React
